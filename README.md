# 📺 IPTV UZ — Telegram Mini App (75+ Jonli Telekanallar)

Barcha ekranlarga to'liq moslashgan (Responsive) zamonaviy jonli telekanallar platformasi:

- 📺 **75+ Jonli Telekanallar:** O'zbekiston milliy telekanallari (ZO'R TV, Sevimli, Milliy, Yoshlar, O'zbekiston, Sport va b.) va xalqaro kinolar, musiqa, bolalar telekanallari.
- 📱 **Barcha Ekranlarga Moslashuvchanlik (Full Responsive Adaptation):**
  - **Smartfonlar:** Yuqori qismida yopishib turuvchi (Sticky) HLS video pleyer, pastda erkin aylanuvchi kanallar ro'yxati (pleyer hech qachon yo'qolib qolmaydi).
  - **Planshet va Noutbuklar:** 2 ustunli teatr/pleylist tartibi (chapda katta pleyer, o'ngda kanallar ro'yxati).
  - **Katta Monitorlar va Smart TV (1200px+):** Keng formatli zamonaviy ko'rinish.
- ⛶ **Katta Ekran (Fullscreen):** Barcha qurilmalarda to'liq ekranga o'tish tugmasi.
- 🔴 **Faqat YouTube Obuna Tizimi:** Telekanallarni ochish uchun faqat YouTube kanalga obuna bo'lish so'raladi.
